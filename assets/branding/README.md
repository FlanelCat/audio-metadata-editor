# Audio Metadata Editor Branding

## Application icon

The Audio Metadata Editor application icon was created specifically for this
project during preparation of the v0.1.0 release.

The design combines three concepts:

- an open book representing audiobooks;
- an audio waveform on the left page;
- stylized metadata fields on the right page.

The artwork was generated with OpenAI image-generation tools under the
direction of Patrick Edlund. It was not copied from another application,
project logo, desktop icon theme, or third-party icon set.

The icon artwork is distributed as part of Audio Metadata Editor under the
project's MIT License.

## Files

`source/audio-metadata-editor-icon-master.png`
: Original approved high-resolution raster artwork (1254 × 1254).

`exports/`
: Derived PNG exports for application and documentation use at 1024, 512, 256,
128, 64, 48, 32, and 16 pixels.

Derived sizes should be regenerated from the master rather than edited
independently.
